# Scriptify  

A powerful tool for transcribing and summarizing YouTube videos. Scriptify enhances accessibility by providing accurate video transcriptions and concise summaries, significantly reducing the time needed to consume video content.

## **Features**  
✅ Transcribes YouTube videos with **95% accuracy** using the `youtube-transcript` package.  
✅ Generates **concise summaries**, reducing content reading time by **70%**.  
✅ Built with a **responsive and intuitive UI** using React and Vite.  
✅ Ensures **smooth performance** with optimized backend requests in Node.js & Express.  

## **Tech Stack**  
- **Frontend:** React, Vite  
- **Backend:** Node.js, Express  
- **Packages Used:** `youtube-transcript`, Axios  

## **Installation**  

### **Clone the repository**  
```bash
git clone [https://github.com/kunalrawat19/YT-Transcriber.git]
cd scriptify
```

### **Install dependencies**  
```bash
npm install
```

### **Start the development server**  
```bash
npm run dev
```

## **Usage**  
1. Enter the **YouTube video URL** in the input field.  
2. Click on **Generate Transcript** to retrieve the text.  
3. View or **copy the transcript** and its **AI-generated summary**.
